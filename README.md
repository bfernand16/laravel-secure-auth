# laravel-secure-auth

Paquete privado con la autenticación de las APIs Laravel + React de Borja: access token JWT de vida corta en memoria,
cookie de renovación rotatoria, verificación en dos pasos (TOTP), step-up para acciones sensibles, sesiones, historial de
seguridad y roles y permisos con reglas CASL.

Contiene dos paquetes en el mismo repositorio:

- `bfernand16/laravel-secure-auth` (Composer, `src/`).
- `@bfernand16/secure-auth` (pnpm, `js/`).

La documentación completa llega con la versión 0.1.0.
